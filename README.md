# mini HR Management — 설치 파일

Windows 용 로컬 인사·근태·급여 관리 앱 **mini HR Management** 의 배포 전용 저장소입니다. 소스 코드는 여기에 없습니다.

## 설치

1. [**최신 릴리스**](https://github.com/ChaeHyunFamily/mini_HR-releases/releases/latest) 의 **Assets** 에서 `miniHR-Setup-X.Y.Z.exe` 를 받습니다.
2. 실행하면 바로 설치됩니다 (관리자 권한 필요 없음).
3. 이미 쓰고 있다면 그 위에 그대로 설치하세요. 데이터(`%APPDATA%\HRManager\hr.sqlite3`)·비밀번호는 그대로 유지됩니다.

설치한 뒤에는 앱이 이 저장소에서 새 버전을 찾아 자동으로 업데이트합니다 (설정 → 업데이트 확인).

> 이 저장소의 파일(`latest.yml` 등)은 앱의 자동 업데이트가 사용합니다. 지우거나 이름을 바꾸지 마세요.
